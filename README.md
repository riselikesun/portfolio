## 🏗️ About This Repository

This is the source code for my personal portfolio at [riselikesun.com](https://www.riselikesun.com/). It's built to showcase production-quality engineering, exceptional UI/UX, and maintainable architecture.

### Tech Stack

| Layer | Technology |
|---|---|
| **Framework** | Next.js (App Router) |
| **Language** | TypeScript (Strict Mode) |
| **Styling** | Tailwind CSS |
| **Animations** | Framer Motion · GSAP · ScrollTrigger · Lenis |
| **UI** | shadcn/ui · Custom Design System |
| **Monorepo** | npm Workspaces |
| **Testing** | Vitest · Storybook · Playwright |

### Project Structure

```
portfolio/
├── apps/
│   └── portfolio/          # Next.js application
│       ├── app/
│       │   ├── components/  # Feature components
│       │   ├── data/        # Content data (experiences, tech, hobbies)
│       │   └── types/       # TypeScript definitions
│       └── public/          # Static assets
└── packages/
    └── ui/                  # Shared component library (@riselikesun/ui)
        └── src/
            ├── components/   # Reusable UI primitives
            └── lib/          # Utilities
```

### Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build
```
