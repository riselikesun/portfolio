# Design Tokens

The Suraj Sharma portfolio utilizes strict semantic design tokens to power its themes. Colors are defined in `globals.css` using `oklch` (for dark mode) and standard hex (for light mode), and mapped to semantic Tailwind classes.

## Theming Philosophy

Our theming system relies on **semantic colors** (`bg-background`, `text-foreground`, `bg-primary`) rather than hardcoded utilities (`bg-white`, `text-black`). This ensures perfect scalability between Light and Dark modes.

### ☀️ Light Mode: Warm & Earthy
The light mode eschews pure white backgrounds for a soft, warm stone gray (`#FAFAF9`), giving a premium Stripe/Apple-like aesthetic. It pairs this with a vibrant Amber primary color (`#C57D24`).

### 🌙 Dark Mode: Deep Gold
The dark mode features an extremely deep background (`oklch(0.145 0 0)`) accented by a rich, elegant Gold (`#D89432`).

## Custom Styling Details

### Premium Scrollbar
We use a bespoke scrollbar implementation to avoid ugly native scrollbars on Windows/Linux:
- **Width**: `6px`
- **Thumb**: Subtle translucent white (`rgba(255, 255, 255, 0.1)`) with a `10px` border radius.
- **Hover**: Fills with the brand primary color with a `0.5` opacity.

### Fractional Opacity Tokens
We heavily utilize Tailwind's fractional opacity syntax (e.g. `bg-foreground/[0.03]`) for overlays. This allows a single class to automatically generate a subtle black overlay in Light Mode, and a subtle white overlay in Dark Mode, ensuring seamless multi-theme support without duplicating CSS.
